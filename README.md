# KCNY

KCNY is a community for people interested in Chinese and Korean culture, language, and friendships.

## First milestone

- Public community feed
- Chinese / Korean interface toggle
- Responsive landing page
- Ready to connect to Supabase for authentication, posts, and comments

## Run locally

Install Node.js 20+ and run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Import this repository into Vercel. The platform detects Next.js automatically; no custom build setting is required.
